Demo runs a deterministic simulator in the browser — no hardware. Connect opens the real board over Web Serial (Chrome or Edge, HTTPS only). There is no analog front end, so amplitudes are shown as raw 12-bit ADC codes (C/DIV, never V/DIV) and every capture is flagged uncalibrated. Logic-analyzer sample rates are nominal.
